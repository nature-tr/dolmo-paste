# r4 评审 → r5 改动

分数：panel(dolmo) 6.8 / panel(system) 7.1 / preview 4.8 / main(dolmo) 5.9 / main(system) 5.7 / OVERALL 6.1
（浮窗两项上升；主窗口和总分下降，主要因为这位评审更看重「侧栏结构 / 关于页卖点 / 说明文案」，这几项都是用户要求保留的）

## 采纳
- 预览卡重做：和浮窗同材质同圆角，图片内嵌 6pt 边 + 内圆角，底部 28pt 信息行「尺寸 · 时间」，右侧显示倍率 / 首次提示
- 预览截图改成「浮窗 + 贴边预览」并排，图片行处于选中，和真实使用一致
- 系统样式行高 40 → 36，前导 24 → 20
- 搜索放大镜中线对齐行首图标中线
- 文件数量挪到标题后面（灰色，同图片尺寸的处理），时间列不再被打乱
- 固定区后加 0.5pt 发丝线（叠在行上不占高度，从文字起点开始）——r3 说留白像 bug，两位评审都接受细线
- dolmo 深色选中 #3F2E1A → #503619（更饱和，不发泥）
- 系统样式主窗口侧栏改原生 .sidebar 材质
- 「清除…」改普通按钮，红色只留在确认框
- 截图模拟材质不透明度 0.74 → 0.82，更接近真实 popover

## 不采纳
- 改成 560px 工具栏式设置窗、隐私并入历史、关于交给系统面板 → 用户确认过的结构
- 删关于页卖点网格、删「切换后下次唤起浮窗生效」→ 用户明确要求保留
- 删通用页脚注 → ⌘ 序号 / ⇥ / → 这三个操作别处没有入口
- 删「粘贴延迟」/ 删浮窗底栏 / 快捷键录制控件 / 样式卡缩小并入分组 → 功能或已确认的结构
- dolmo 改单行 → 同 r3
- 截图标题改 OCR 首行 → OCR 默认关闭，多数情况拿不到
- 「行标签 semibold」「蓝色写死」→ 核实代码：标签是 13pt regular，颜色用的是 Color.accentColor，误判
