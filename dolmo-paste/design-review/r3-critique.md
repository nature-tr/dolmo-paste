# r3 评审 → r4 改动

分数：panel(dolmo) 6.4 / panel(system) 7.1 / preview 5.6 / main(dolmo) 6.2 / main(system) 6.9 / OVERALL 6.5

## 采纳
- dolmo 深色改暖黑：底 #1A1714、侧栏 #221E1A、分组 #27221D、分隔 #332D27
- 选中态统一只用填充：去掉 selectedStroke 字段；深色填充 #3F2E1A（橙 16% 叠暖黑）
- 固定区后的空白删掉（连带删 pinnedSplitIndex / pinnedGap / hasPinnedSplit）
- 右侧固定 14pt 图钉槽，时间列对齐
- ⌘N 默认隐藏，按住 ⌘（单独）时前 9 行一起显示（监听 flagsChanged）
- 元信息不再写来源 App 文字
- 预览卡圆角跟随浮窗（theme.cornerRadius）
- 样式缩略图：画完整行不切半截；dolmo 深色选中自动用新填充
- 通用页：开机启动 + 唤起快捷键合为「使用」组；脚注只说浮窗里不显眼的操作
- 历史页：统计压成「N 条记录 · 占用 X · 始于 …」；OCR 并入「记录」组，说明改行内副标题
- 隐私页：没装的默认项不逐行列出，收成脚注「另有 N 个…装上后自动生效」

## 不采纳
- dolmo 文本行改单行 → 两行是 dolmo 与系统样式的结构区分，系统样式已经是高密度版本
- 图钉改灰 → 叶绿取自图标；⌘N 默认隐藏后不再与橙色抢
- 预览卡底部信息栏 → 行里已有尺寸和时间，r1 刚删掉；缩放时胶囊已显示尺寸和倍率
- 删除关于页功能网格 / 「切换后下次唤起浮窗生效」→ 用户明确要求保留
- 快捷键可录制 → 功能范畴
- 改成工具栏式小设置窗 → 结构性大改，与用户已确认的侧栏主窗口冲突
- 标题去掉「截图/图片」→ 截图与普通图片的区分是有用信息
- 「dolmo design」改名 → 用户起的名字
