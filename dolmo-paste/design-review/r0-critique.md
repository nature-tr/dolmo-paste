## 采纳（按优先级）
1. 强调色不是品牌色：靛紫和橙子图标毫无关系 → 橙色为唯一强调色，叶绿为第二色（固定 / 已授权）
2. 每行一张白卡 + 三重选中态（底色 + 左侧条 + 序号着色）→ 连续纸面，选中只用一种表达
3. 侧边栏品牌头压在红绿灯上（真 bug）→ 去掉，导航从 52px 开始
4. 预览卡：卡中卡、标注比图片还大、提示常驻 → 贴合图片比例、小标注、提示只在首次出现
5. 行结构：所有文本都是同一个灰色文档图标；代码折行带 ↩；「[图片 1020×740]」像调试输出 → 来源 App 图标做前导，代码单行等宽，图片标题去方括号
6. 提示徽章过多（6 个底部 chip + Tab 切换 + 带图标带边框的过滤器）→ 底部只留 3 个纯文本提示，过滤器纯文字
7. 设置页：统计格子与卡片不对齐、分区标题在卡内、每页副标题复述导航、危险操作无区分 → 统计压成一行、标题移到分组外、删副标题、「全部清除」红字
8. 系统样式不够原生：行有边框、76px 高、无毛玻璃 → 平铺列表 + popover 材质 + 单行 40px + 原生分段控件
9. 深色模式只是换色：对比度不足、样式缩略图不跟随 → 暖黑、次级文字 ≥60%、缩略图跟随主题
