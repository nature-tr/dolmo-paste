## 3. 描述（Description）

```
dolmo paste 是常驻菜单栏的剪贴板历史，⌘⇧V 一唤即用：打字就搜，回车就粘。

不用再翻回刚关掉的窗口找那段复制的文字。它替你记住复制过的文本、图片和文件，随时唤起、随手粘贴。

主要功能
· 全局热键唤起：默认 ⌘⇧V，可在设置里改成任意组合；在输入框旁原地弹出，不打断当前工作
· 选中即直接粘贴：一条内容直接粘进当前 App，不用先粘到别处再搬
· 打字即搜索：文本、来源 App 都能搜，图片里的文字也能被搜到（可选）
· 悬停预览图片：鼠标停在图片条目上就出预览卡，支持缩放、复制、直接粘贴
· 键盘直达：⌘1–9 直接粘贴前 9 条，↑↓ 选择，⇧⏎ 只粘纯文本，⌘P 固定，Tab 切换类型
· 合并粘贴：⌘M 勾选多条，回车一次拼好贴出
· 片段库：邮箱、地址、签名这类总要粘的内容存成片段，支持 {{date}} {{time}} {{clipboard}} 变量，粘贴时自动替换
· 类型筛选：全部 / 固定 / 文本 / 图片 / 文件 / 片段
· 来源标注：每条都显示复制自哪个 App 和复制时间
· 固定常用内容：常贴的地址、命令、邮箱固定住，不会被自动清理
· 两套外观：系统样式 或 dolmo design，自动跟随浅色 / 深色模式

隐私优先
· 完全本地：不联网、不上传、不共享，应用内没有任何网络请求代码
· 不记密码：被密码管理器标记为机密的内容一律不记录，并内置常用密码管理器排除名单
· OCR 可选：图片文字识别默认关闭，开启后也在本机离线完成
· 清理简单：主窗口一键清除历史，或直接删除本地数据目录

说明：把内容直接粘贴进当前 App、以及让浮窗贴着光标显示，需要「辅助功能」权限。不授予也能正常使用，只是需要你自己按一下 ⌘V。
```

## 7. 审核备注（App Review Notes）

```
【应用简介】
dolmo paste 是一款完全在本地运行的 macOS 剪贴板历史工具，常驻菜单栏（LSUIElement）。
应用内没有任何网络请求代码，不含账号体系、内购或登录；所有数据只保存在本机。
首次启动会自动打开一次主窗口，之后通过菜单栏图标（橙色橙子）访问。

【关于辅助功能（Accessibility）权限——请重点了解】
应用只申请「辅助功能」这一项权限，用途严格限定为两件本机操作：
  1. 模拟 ⌘V：从历史中选中一条内容后，把内容写回系统剪贴板，并通过 CGEvent 模拟一次 ⌘V，
     直接粘贴进用户当前正在使用的 App。
  2. 定位光标/输入框：通过系统辅助功能接口
     （AXUIElementCreateSystemWide + kAXFocusedUIElementAttribute + kAXFrameAttribute）
     读取当前聚焦输入元素的位置，把浮窗面板显示在输入光标旁边，而不是固定弹在屏幕角落。
应用不会读取、记录或上传其它 App 中的任何内容，也不收集键盘输入。
未授予该权限时功能会自动降级：只把内容写回剪贴板，由用户手动按 ⌘V，其余功能（浏览、
搜索、图片预览、历史管理、设置）全部正常。首次启动会弹出说明用途的对话框，并提供
跳转到「系统设置 → 隐私与安全性 → 辅助功能」的按钮。

【测试步骤】
1. 启动应用。首次启动会弹出权限说明，点「前往系统设置」并勾选 dolmo paste
   （若已跳过，可到 系统设置 → 隐私与安全性 → 辅助功能 中手动勾选）。
2. 在任意 App 中复制几段文字（⌘C）、复制一张图片（例如用 ⇧⌘4 截图）、复制几个文件。
3. 按全局热键 ⌘⇧V 唤起浮窗，应弹出历史列表，内容按时间倒序，并显示来源 App 图标与时间。
4. 在浮窗中直接打字即可搜索（支持中文与拼音）。
5. 用 ↑/↓ 选择一条，按 Return，内容应直接粘贴到第 2 步所在的 App 中；
   按 ⇧Return 则只粘贴纯文本；按 ⌘1–9 可直接粘贴前 9 条。
6. 将鼠标悬停到列表中的图片条目上，右侧应弹出该图片的预览卡；点击可打开大图查看器。
7. 菜单栏橙色橙子图标：左键打开主窗口（含「通用 / 历史与存储 / 片段 / 隐私 / 关于」五个页面），
   右键弹出菜单（打开历史 / 清除历史 / 退出）。
8. 在浮窗中按 Tab 循环到「片段」栏，可看到片段列表；片段可在主窗口「片段」页增删改。

【其它说明】
· 默认全局热键为 ⌘⇧V，可在主窗口「通用」页查看；未注册成功时以菜单栏右键菜单中的
  「打开历史」为入口。
· 「识别图片里的文字」（OCR）默认关闭；开启后使用系统 Vision 框架在本机离线识别，
  图片不会离开设备。
· 应用不申请网络、屏幕录制、麦克风、相机、通讯录、定位等任何其它权限。
· 无账号、无内购；「历史与存储」页可一键清除全部历史，数据目录位于应用本地容器内。
· 主窗口侧栏顶部展示的本机 Apple 账户名称与头像，来自系统已有的本地记录，不联网获取。
```
